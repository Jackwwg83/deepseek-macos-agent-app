# Tester Alpha Delivery

The tester-ready package is generated by:

```bash

```


## Tester Flow

Testers only need three runtime values:

1. DeepSeek-compatible URL, such as `https://api.deepseek.com/beta`, `https://your-host/v1`, or `http://your-self-hosted-server:port/v1`.
2. DeepSeek API key.
3. Model name, such as `deepseek-v4-flash`.

Steps:

1. Unzip `DeepSeek-Agent-alpha-macos.zip`.
2. Open `DeepSeek Agent.app`.
3. Complete the First Run Setup screen.
4. Enter the DeepSeek URL, API key, and model, then click `Complete Setup`.
5. The app saves the API key to macOS Keychain and clears the setup field after submit.
6. Optional: enable Demo Mode only for offline UI diagnostics without a real endpoint.

The app bundles `deepseek-tui`; testers do not need Rust, Node, Xcode, or a separate DeepSeek-TUI install.

## Security Notes

- The API key is stored in macOS Keychain, not in package files.
- The local runtime binds to `127.0.0.1`.
- A fresh runtime bearer token is generated by Swift for each launch.
- The WebView does not store the runtime bearer token.
- `https://` is recommended. `http://` is allowed for self-hosted or private-network endpoints, and the app shows a warning because API keys are not protected by TLS on HTTP.

## macOS Gatekeeper Note

This is an ad-hoc signed, not notarized alpha build. If macOS blocks it after download, testers can right-click the app and choose `Open`. For local controlled testing, this command also clears quarantine:

```bash
xattr -dr com.apple.quarantine "DeepSeek Agent.app"
```
